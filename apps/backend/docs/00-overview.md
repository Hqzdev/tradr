# TRADR backend: актуальный обзор

Этот документ описывает то, что действительно работает в проекте сейчас.
Старый сценарий с ручным терминалом больше не является частью продукта:
покупать и продавать могут только агенты.

## Что делает backend

Backend — это приложение на Java 21 и Spring Boot. Оно:

- регистрирует пользователей и выдаёт JWT-токены;
- создаёт учебный счёт на 100 000 USD;
- хранит цель пользователя и режим ускорения;
- создаёт агентов и переводит им часть резерва;
- генерирует учебные рыночные цены;
- разрешает активным агентам покупать и продавать;
- считает капитал, прибыль и историю решений;
- сохраняет данные в PostgreSQL.

## Главный пользовательский сценарий

1. Пользователь проходит регистрацию.
2. В той же транзакции создаются счёт и первый остановленный агент.
3. Пользователь попадает на Dashboard и запускает агента.
4. Агент получает тики всех акций и ищет подходящие сделки.
5. Покупка или продажа меняет только кошелёк и позиции этого агента.
6. Dashboard складывает резерв и стоимость всех агентов.

## Архитектура

```text
Next.js frontend
       │ REST / WebSocket
       ▼
Spring Boot backend
       ├── auth       — пользователи и токены
       ├── dashboard  — капитал, цель и активность
       ├── market     — инструменты, свечи и тики
       ├── agents     — стратегии, кошельки и позиции
       ├── trading    — исполнение агентских сделок
       └── common     — единый формат ошибок
       │
       ▼
PostgreSQL + Flyway
```

Это модульный монолит: один процесс, разделённый на предметные области.
Микросервисы для текущего масштаба не нужны.

## Что важно знать о Java-коде

- `Controller` принимает HTTP-запрос.
- `Service` выполняет бизнес-сценарий.
- `Repository` читает или сохраняет базу.
- `Entity` соответствует данным в таблице.
- `DTO` определяет безопасный JSON для клиента.
- `@Transactional` делает несколько изменений одной операцией.

Финансовые значения считаются через `BigDecimal`, а не `double`.

## Рынок

Сейчас подключён только `SyntheticMarketDataProvider`. Он создаёт
воспроизводимые режимы роста, падения и бокового движения. Реальный
биржевой API ещё не реализован. Наличие `FINNHUB_API_KEY` само по себе не
изменит источник данных.

## Локальная инфраструктура

- frontend: Node.js 20 и Next.js 14;
- backend: Java 21 и Spring Boot 3;
- база: PostgreSQL;
- схема: Flyway V1–V15;
- локальная база: Docker или OrbStack.

## Продакшен

Frontend можно разместить на Vercel. Backend нужно размещать как
долгоживущий Java-процесс на Railway, Render, Fly.io, VPS или другом
контейнерном хостинге. Он постоянно выполняет tick-движок и держит
WebSocket, поэтому обычная serverless-функция Vercel ему не подходит.
