# Логика торговли

`OrderCalculator` повторяет прежний расчёт frontend: до восьми знаков в количестве акций, до двух знаков в деньгах и комиссия 0.1%.

`TradingService` создаёт заявку, проверяет деньги или акции, записывает сделку, меняет баланс и обновляет позицию. Рыночная заявка исполняется сразу. Лимитная ждёт подходящую цену и проверяется на каждом новом тике рынка.
