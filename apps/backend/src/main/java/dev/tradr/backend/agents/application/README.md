# Логика агентов

`AgentProvisioner` атомарно создаёт агента, конфигурацию, кошелёк и первую
точку капитала. `AgentService` запускает, останавливает и закрывает агента,
обрабатывает каждый разрешённый рыночный шаг и сохраняет решения.

`AgentTradingPolicy` задаёт число позиций, размер покупки, take-profit и
stop-loss. Продажа проверяется раньше новой покупки; cooldown равен 10
симулированным шагам, выход по времени — 390 шагам.
