# Phase 2: рынок простыми словами

Phase 2 добавляет в backend живой учебный рынок. Теперь сервер знает шесть
акций, хранит их свечи в PostgreSQL, отдаёт данные по HTTP и сам периодически
меняет цену. Это synthetic market: цены придуманы сервером для разработки,
а не загружаются с биржи.

## Что теперь есть

В базе появились шесть акций:

| Тикер | Компания | Стартовая цена |
| --- | --- | ---: |
| AAPL | Apple Inc. | 192.45 USD |
| NVDA | NVIDIA Corporation | 138.72 USD |
| TSLA | Tesla, Inc. | 247.18 USD |
| MSFT | Microsoft Corporation | 428.76 USD |
| AMZN | Amazon.com, Inc. | 186.42 USD |
| GOOGL | Alphabet Inc. | 167.28 USD |

Также есть три индекса: S&P 500, NASDAQ и DOW JONES.

После запуска backend сам создаёт историю свечей для каждого инструмента.
Есть пять таймфреймов: `1m`, `5m`, `15m`, `1h` и `1d`. Свеча содержит цену
открытия, максимум, минимум, цену закрытия, объём и время.

## Как движется цена

`SyntheticMarketDataProvider` хранит повторяемый сценарий небольших изменений
цены. Благодаря этому рынок выглядит живым, но остаётся предсказуемым:
одинаковый запуск создаёт понятные данные, а не случайный набор чисел.

`MarketTickEngine` запускается каждые 2.6 секунды. На каждом шаге он:

1. Берёт следующую цену для каждого из шести тикеров.
2. Обновляет текущую минутную свечу в PostgreSQL.
3. Отправляет новую котировку всем WebSocket-клиентам, подписанным на этот тикер.

Текущая цена берётся из последней минутной свечи, поэтому HTTP API и WebSocket
используют одни и те же данные.

## Где лежит код

Весь рынок находится в `src/main/java/dev/tradr/backend/market`.

- `domain` — сущности базы данных: инструмент, свеча, индекс и таймфрейм.
- `repository` — запросы к PostgreSQL.
- `provider` — генератор synthetic-данных.
- `application` — запуск истории, чтение рынка и tick-движок.
- `web` — REST-контроллеры.
- `web/dto` — формат JSON-ответов.
- `websocket` — соединения клиентов и рассылка тиков.
- `exception` — ошибки рынка, например неизвестный тикер.

В каждой из этих папок есть короткий README с назначением папки.

## База данных и миграции

`V3__market.sql` создаёт три таблицы:

- `instruments` — список торгуемых акций;
- `candles` — история OHLCV-свечей;
- `index_quotes` — значения индексов для верхней плашки рынка.

`V4__fix_instrument_currency_type.sql` исправляет тип поля `currency`, чтобы
PostgreSQL и JPA одинаково его понимали. Это отдельная миграция специально:
уже применённые миграции не редактируют задним числом.

## HTTP API

Все market-эндпоинты доступны без токена. Рыночные данные не содержат данных
пользователя, а такое решение позволяет браузеру подключаться к WebSocket
без передачи JWT в URL.

### Индексы

```bash
curl -s http://localhost:8080/api/v1/market/indices | jq
```

Возвращает три индекса с отображаемым значением и изменением в процентах.

### Все инструменты

```bash
curl -s http://localhost:8080/api/v1/instruments | jq
```

Возвращает список акций с текущей ценой, изменением, объёмом, валютой и биржей.

### Карточка акции

```bash
curl -s http://localhost:8080/api/v1/instruments/AAPL | jq
```

Возвращает инструмент, текущую котировку, метрики и synthetic-news для карточки.

### Свечи для графика

```bash
curl -s 'http://localhost:8080/api/v1/instruments/AAPL/candles?timeframe=5m&limit=24' | jq
```

`timeframe` принимает только `1m`, `5m`, `15m`, `1h` или `1d`.
`limit` может быть от 1 до 500. Неверный таймфрейм возвращает `400`,
несуществующий тикер возвращает `404`.

### Текущая котировка и новости

```bash
curl -s http://localhost:8080/api/v1/instruments/AAPL/quote | jq
curl -s http://localhost:8080/api/v1/instruments/AAPL/news | jq
```

## WebSocket

Подключение к одному инструменту выглядит так:

```text
ws://localhost:8080/ws/market/AAPL
```

Сразу после соединения сервер присылает текущую цену. Затем приходит новое
сообщение после очередного тика. Формат сообщения:

```json
{
  "ticker": "AAPL",
  "price": 192.47,
  "changePercent": 1.85,
  "ts": "2026-09-18T17:20:00Z"
}
```

## Как проверить, что всё работает

1. Подними Postgres: `docker compose -f docker-compose.dev.yml up -d`.
2. Запусти backend с переменными из `.env`.
3. Вызови `GET /api/v1/instruments` и убедись, что пришло шесть акций.
4. Вызови свечи AAPL на `5m` с `limit=24`.
5. Два раза с паузой в три секунды вызови `/api/v1/instruments/AAPL/quote`.
   Цена должна измениться.
6. Подключись к `ws://localhost:8080/ws/market/AAPL` и дождись второго сообщения.
