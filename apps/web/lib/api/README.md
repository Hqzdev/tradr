# API фронтенда

В этой папке лежат небольшие функции для общения с backend.

- `client.ts` добавляет адрес backend и токен входа к запросу.
- `auth.ts` отвечает за регистрацию, вход, выход и текущего пользователя.
- `agents.ts` создаёт агентов, получает список и меняет их статус.
- `trading.ts` получает портфель, заявки и историю сделок.
- `market.ts` получает список рыночных инструментов и котировки.

Экран не хранит готовые торговые цифры в коде. Он запрашивает backend и
показывает пустое состояние, пока пользователь ещё не создал данных.
