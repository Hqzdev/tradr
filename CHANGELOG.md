# История изменений

Все заметные изменения TRADR фиксируются в этом файле.

Формат основан на принципах [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), а версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Корневой npm-workspace для совместного запуска фронтенда и бэкенда командой `npm run dev`.
- Базовая русскоязычная документация по разработке, архитектуре, участию и безопасности.
- Документация сайта расширена до 38 статей с отдельными блоками Frontend и Backend.
- Добавлены простые статьи о Java, пользовательском пути, Dashboard, миграциях, тестировании и деплое.
- В статье Backend → «Агенты» добавлена простая карта папки `agents/application` и отдельное объяснение `AgentProvisioner`, `AgentService`, `AgentTradingPolicy` и локального README.
- В Backend добавлена отдельная статья о папке `agents/domain`: моделях агента, кошельке, позициях, истории решений и правилах бюджета.
- В Backend добавлена статья о папке `agents/exception`, AgentAllocationException и возврате ошибки конфликта в интерфейс.
- В Backend добавлены отдельные статьи о корне `auth` и каждой его подпапке: application, domain, exception, repository, security, web и web/dto.
- В Backend добавлены статьи о папках `common` и `common/api`: общем контракте ошибок, ErrorResponse и GlobalExceptionHandler.

### Изменено

- Удалены устаревшие инструкции по ручному терминалу, старому маленькому агенту и несуществующему Finnhub-провайдеру.
- Блок «На этой странице» приведён к лёгкому типографическому стилю референса.
- Прокрутка sidebar документации сохраняется при переходе между статьями.
- Подсветка «На этой странице» теперь выбирает раздел, к которому пользователь действительно прокрутился.
