# Торговля

Этот модуль исполняет сделки только от имени агентов и отдаёт историю для просмотра.

- `application` считает комиссию и атомарно выполняет агентскую сделку.
- `domain` описывает заявки, сделки, источник и направление операции.
- `repository` читает и сохраняет данные в PostgreSQL.
- `web` принимает HTTP-запросы и отдаёт JSON.
- `exception` содержит понятные ошибки торговли.

Публичный Controller содержит только GET-запросы. Новую операцию вызывает
`AgentService` через `TradingService.executeAgentOrder`.
