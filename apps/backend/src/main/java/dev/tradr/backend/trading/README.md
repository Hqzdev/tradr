# Торговля

Этот модуль отвечает за ручную торговлю пользователя.

- `application` считает цену заявки и выполняет сделки.
- `domain` описывает ордера, сделки и текущие позиции.
- `repository` читает и сохраняет данные в PostgreSQL.
- `web` принимает HTTP-запросы и отдаёт JSON.
- `exception` содержит понятные ошибки торговли.

Все пути начинаются с `/api/v1`. Для них нужен access-токен из login или register.
