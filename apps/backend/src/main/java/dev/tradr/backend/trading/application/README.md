# Логика торговли

`OrderCalculator` считает до восьми знаков в количестве акций, до двух знаков в деньгах и комиссию 0.1%.

`TradingService` проверяет кошелёк и позицию конкретного агента, создаёт
заполненные Order и Trade, затем обновляет `AgentWallet` и `AgentPosition`.
Ручное создание заявки через HTTP не поддерживается.
