# Pro-агенты

Карточки линейки «Скоро» находятся в [`pro-agents.json`](./pro-agents.json).
Чтобы добавить карточку, добавьте объект в массив:

- `icon`: `shield`, `target` или `infinity`;
- `rarity`: `epic`, `legendary` или `mythic`;
- `name`: имя агента;
- `tag`: короткое описание;
- `color`: цвет карточки в hex;
- `text`: описание поведения;
- `skills`: список навыков с `name` и оценкой `value` от 0 до 100.
- `abilities`: уникальные функции агента с `name` и `description`. Не копируйте
  функции между агентами, чтобы у каждого был свой набор.

После сохранения Next.js обновит страницу `/agents/pro`.
